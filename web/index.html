      About this project

      Project overview

      Hospital Appointment Booking System using GitHub and Docker — a DevOps project with user registration, hourly slot booking, and email/SMS confirmations.

      Features

      • Login and registration
      • Fixed hourly slots with live availability
      • Suggested slots when your choice is taken
      • Email and SMS booking confirmation
      • Docker deployment and Jenkins CI/CD

      • Node.js API
      • SQLite
      • Docker
      • Jenkins
